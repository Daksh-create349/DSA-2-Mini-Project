# Four-Slide Presentation Outline

**Case Study No. 02 — Range Minimum Query with Point Updates**  
**Prepared by:** Daksh Srivastava, Prathamesh More, Yuvraj Mishra, Biswajeet Rout, Sumit Shingole

1. **Scenario:** road-segment scores; inclusive range minimum queries; individual score changes.
2. **Approaches:** linear scan, sparse table, and segment tree, with time and memory complexity.
3. **Evidence:** same benchmark workloads, query/update timings, and labelled black-and-white chart.
4. **Recommendation:** segment tree for changing data; sparse table for static data; linear scan for very small inputs.
